# Migration From 1.0.0-rc.1 To 1.0.0-rc.2

RC.2 narrows the exported assembly surface before the stable API lifecycle
begins.

## Removed Public Surface

Repository governance models under `Sigtran.NET.Core.Utilities` are now
internal. This includes release workflow plans, evidence dossiers, readiness
catalogs, package publication gates, supply-chain planning models, compliance
catalogs, and phase status helpers.

These types described how this repository is developed and released. They were
not protocol or runtime contracts and should not have been exported by the SDK.

Applications that used them should move release governance into their own CI
configuration and use the version-controlled artifacts under `eng`, `.github`,
and `docs` as examples. There is no runtime replacement because these types did
not carry signaling traffic.

## Added Runtime Surface

RC.2 adds the supported layer and operations contracts:

- `ISctpTransport` and `ISctpAssociation`
- `IMtp2Link` and `IMtp3Network`
- `ISccpService`
- `ITcapDialogues` and component dialogue APIs
- `IMapSmsService`
- `M3uaRuntime`
- `M2paLink`
- `SccpConnectionlessService`
- `TcapDialogueManager`
- `MapSmsService` and `MapSmsServer`
- `SigtranHealthService` and runtime probes
- `SigtranTelemetry`
- `ISigtranEventSink` and `JsonLineSigtranEventSink`
- `SigtranNodeConfigurationParser`

## Package Version

Source builds and normal CI packing now default to `1.0.0-rc.2`. Stable
`1.0.0` can only be produced by the protected release workflow with an explicit
version override and a passing stable release decision.

RC.2 is not published by this migration document. Publication remains a
separate guarded action.
