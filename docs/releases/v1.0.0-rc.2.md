## Overview

SIGTRAN.NET v1.0.0-rc.2 is the current source-level release candidate for the first open-source .NET 10 SDK dedicated to SIGTRAN and SS7-over-IP protocol engineering.

This release-candidate track expands the SDK beyond codec-only foundations into stateful runtime services, native Linux SCTP transport evidence, cross-implementation MAP SMS traffic evidence, operations APIs, and release-governed production-readiness gates.

This RC is intended for controlled integrations, lab testing, protocol review, interoperability feedback, and contributor validation. It must not be represented as a fully stable operator-grade SS7/SIGTRAN stack until the remaining stable gates are closed.

## Highlights

- .NET 10 SDK targeting SIGTRAN and SS7-over-IP applications.
- Native Linux SCTP transport direction with retained stream/PPID/metadata evidence.
- M3UA runtime support with codec, routing, ASP state, diagnostics, and external peer evidence.
- M2PA runtime foundation with RFC 4165 alignment and independent peer evidence still pending.
- Stateful SCCP service with UDT/XUDT/LUDT, global-title translation, segmentation/reassembly, metrics, and cancellation behavior.
- TCAP dialogue manager with Begin/Continue/End/Abort, invoke tracking, results, errors, rejects, timeout scanning, and cleanup.
- MAP SMS workflows for SRI-SM, MO/MT ForwardSM, ReportSM-DeliveryStatus, and AlertServiceCentre.
- Cross-implementation full-stack MAP SMS traffic evidence through TCAP, SCCP, M3UA, and native SCTP.
- Runtime health probes, structured JSONL events, BCL/OpenTelemetry-compatible tracing and metrics, validated configuration, container/Kubernetes manifests, and operations runbooks.
- Public API surface governance and stable-release gate evaluation.

## Known stable blockers

Stable publication remains blocked until the following evidence exists and passes the governed release gate:

- Independent external M2PA peer evidence.
- Operator/vendor-profile SCCP, TCAP, and MAP SMS interoperability evidence.
- Representative multi-host performance evidence that reaches the stable target.
- Long-duration multi-host soak evidence.
- Representative Kubernetes SCTP/CNI deployment evidence.
- Organization-trusted package signing evidence.
- Matching protected stable tag/release workflow execution.
- Verified stable NuGet publication and restore evidence.
